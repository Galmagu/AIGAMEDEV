# 뱀서라이크 프로토타입 개발 명세 (v0 — 장르 표준안)

> 이 문서는 **전형적인 뱀서라이크의 표준 스펙**을 정리한 초안이다.
> 여기서 바꿀 항목을 골라 v1 명세로 확정한다.
> 각 항목의 ID(예: `P-03`)로 "이건 바꾸자 / 빼자 / 유지"를 지정하면 된다.
> 수치는 레퍼런스 게임의 정확한 값이 아니라 **프로토타입 시작값**이다. 플레이테스트로 조정한다.

## 1. 코어 루프

```
이동 → 자동 공격 → 적 처치 → 경험치 젬 드랍 → 줍기
  → 레벨업 → 업그레이드 3택1 → 강해짐
  → 시간 경과로 적 증가/강화 → (반복)
  → 사망 or 생존 → 결과 화면 → 골드로 영구 강화 → 다음 판
```

| ID | 항목 | 표준안 |
|---|---|---|
| L-01 | 플레이어 조작 | **이동만** 한다. 공격은 전부 자동 |
| L-02 | 성장 | 판 안에서의 성장(레벨업)이 메인, 판 밖 성장(메타)은 보조 |
| L-03 | 긴장 곡선 | 초반 약함 → 중반 빌드 완성 → 후반 물량에 압살 or 무쌍 |

## 결정이 필요한 주요 포인트

게임 정체성을 가르는 항목들. 여기서 하나라도 바꾸면 "그냥 뱀서 클론"을 벗어난다.

1. **조작** (C-02): 완전 자동 유지? 수동 조준/액티브 스킬 추가?
2. **한 판 길이** (G-02): 15분? 더 짧게(5~10분)?
3. **성장 구조** (W-02~W-04, I-01): 6+6 슬롯과 진화 시스템 유지? 다른 빌드 방식?
4. **맵** (M-01, M-02): 무한 빈 필드? 지형/장애물/구역?
5. **적 AI** (E-01): 단순 추적? 패턴 있는 적?
6. **메타 진행** (R-01~R-05): 넣을까, 뺄까?
7. **테마/세계관**: 고딕 호러(레퍼런스)? 다른 테마?
