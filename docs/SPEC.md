> v0(장르 표준안)에서 확정한 변경 사항을 반영한 명세다.
> **(가정)** 표시는 아직 결정되지 않아 기본값으로 채운 항목이다. 문서 맨 아래 "미결정 사항"에 모아뒀다.

### 장르 표준과 다른 점 (이 게임의 정체성)

1. 무기를 모으는 대신 **동료를 모은다**. 동료 한 명 = 무기 하나
2. 동료가 주인공을 따라 **떼로 몰려다닌다**
3. 주인공과 동료 모두 **각자의 체력**이 있어서, 동료가 죽으면 화력이 줄어든다
4. 보상 경로가 셋으로 나뉜다: 레벨업은 동료, 네임드는 패시브, 보스는 부활/대강화

## 1. 코어 루프

```
이동 → 갱 전원 자동 공격 → 적 처치 → 경험치 조각 줍기
  ├─ 레벨업        → 동료 3택1 영입 → 갱 규모 증가
  ├─ 네임드 처치   → 경험치 다량 + 패시브 3택1 → 갱 전체 강화
  └─ 보스 처치     → 경험치 대량 + [동료 부활 / 동료 무기 대강화] 3택1
  → 동료 사망으로 화력 감소 ↔ 보스 보상으로 복구
  → 8분 생존 or 주인공 사망 → 결과 화면
```
